# Interval Open

Interval Open combines a barless capital A with an omission in R's upper left stem. The same construction applies to accented forms. It includes Regular, Medium, and Bold in TTF and WOFF2 formats, with the same 366-character coverage as [Interval](../../README.md). Version 1.102.

Install the TTF files in [fonts](fonts) through your operating system's font manager. For web use, copy the `fonts` directory with [interval-open.css](interval-open.css) and load that stylesheet. Select `font-family: "Interval Open"` with `font-weight: 400`, `500`, or `700`.

Follow the [Interval build instructions](../../README.md#build) to rebuild the fonts from source. The separately named family can be installed alongside Interval and Interval Barless.
