# Interval Barless

Interval Barless removes the crossbar from capital A and its accented forms. It includes Medium in TTF and WOFF2 formats, with the same 366-character coverage as [Interval](../../README.md). Version 1.102.

Install [interval-barless-medium.ttf](fonts/interval-barless-medium.ttf) through your operating system's font manager. For web use, copy the `fonts` directory with [interval-barless.css](interval-barless.css) and load that stylesheet. Select `font-family: "Interval Barless"` with `font-weight: 500`.

Follow the [Interval build instructions](../../README.md#build) to rebuild the font from source. The separately named family can be installed alongside Interval and Interval Open.
